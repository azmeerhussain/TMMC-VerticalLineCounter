Problems I ran into

1. Lines are thick, so I couldn't just count black columns. I count each
   run of black pixels in a row as one line instead.

2. img_3 is completely black, and the first line in img_4 touches the
   left edge. Counting only white-to-black changes missed these, so a
   black pixel at x = 0 also counts as the start of a line.

3. JPG compression adds grey pixels around the line edges, so checking
   for pure black (0,0,0) isn't reliable. I use a brightness threshold
   of 128 instead.

4. Some lines don't reach the top or bottom of the image (img_2). Since
   every line crosses both halves, I scan the middle row.

5. ImageIO.read() returns null instead of throwing for non-image files,
   so I check for null to avoid a crash.
